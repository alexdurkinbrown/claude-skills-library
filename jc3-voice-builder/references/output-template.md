## Generation Instructions

1. **Fill in every bracketed field** with specific information from the session. No generic placeholders.

2. **The voice summary** is the most important section. It should be 2–3 sentences that capture the essence of the voice. If someone read only this section, they should know how to write for this brand.

3. **Every rule should have an example** from the user's actual writing or from the approved test outputs. Rules without examples are too abstract to follow.

4. **The calibrated examples** are the three outputs from the live test that the user approved. These are the gold standard . they are the voice working correctly.

5. **The never-say list** should include at minimum:
   - Words from the anti-voice discussion
   - Generic corporate language the user's industry overuses
   - Any words that appeared in the "generic" version during the delight comparison but not in the user's real writing

6. **If creating the file with tools**, save as `my-brand-voice.md` and present for download.

7. **If no file tools**, output in a markdown code block with instructions to copy and save.

8. **After presenting the file**, transition to the close (Phase 7 of the session flow).
