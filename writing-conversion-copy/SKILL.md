# Section A — Customer Insights to Messaging

## Inputs
Customer interviews, reviews, support tickets, survey data, or sales call notes. Plus: product/service being analyzed, current positioning.

## Process
1. **Categorize**: Complaints / Desires / Jobs-to-be-done / Comparison points / Outcome language (exact customer words)
2. **Five Whys** (top 5–7 recurring issues): Surface problem → Why × 5 = Root Cause. Flag which root causes your product addresses vs. leaves unaddressed (product gaps)
3. **Insight Map** (Sheets): Theme | Frequency | Sentiment | Root Cause | Addressable? | Positioning Angle — sorted by frequency × emotional intensity

## Output
- 10 positioning angles: "For [customer] who [problem], [X] is [solution] that [outcome], unlike [alternative]"
- Messaging variations for top 5 angles: headline (10 words) / subheadline (25 words) / body hook (50 words) — using customer's exact language
- Strategic brief: top 3 findings, recommended positioning shift, 3 immediate marketing actions

# Section B — Full Sales Letter

## Inputs
Product/service, ideal customer + core problem, primary benefit/transformation, price point, proof available (testimonials/data/credentials), delivery format (web/email/PDF).

## Structure (Ogilvy/Halbert Formula)
1. **Headline** — specific, benefit-driven, curiosity or news hook
2. **Deck copy** — 2–3 lines bridging headline to body
3. **Opening** — story or problem statement, emotional pull
4. **Agitation** — make the problem vivid and costly
5. **Solution** — position offer as the logical answer
6. **Credibility** — why you/this product delivers
7. **Benefit Bullets** — 10–15 outcome-focused: "You'll [outcome] so that [deeper benefit]"
8. **Social Proof** — testimonials, results, case study
9. **The Offer** — exact deliverables, value stack, price anchor
10. **Guarantee** — specific, named risk reversal
11. **Urgency/Scarcity** — real reason to act now
12. **CTA** — direct, specific, low-friction
13. **P.S.** — restate best benefit + urgency (most-read element)

Margin notes on psychological principle at each section.

## Also Deliver
- 5 headline variations: specific result+timeframe / curiosity gap / loss aversion / social proof anchor / "how to"+unexpected element
- 5 CTA variations: standard / risk-reversal / scarcity / social proof / soft retargeting
- 400-word email version (same structure, mobile-optimized, single CTA)

## Quality Gates
Every line passes: so-what test / specificity test (numbers, names, outcomes) / empathy test / action test.

# Section C — Copy Structure & Outline

## Inputs
Target customer, core problem, offer, proof available, top objections, price point.

## Deliverables
1. **Customer Psychology Map**: Dominant emotion on arrival / core desire / biggest fear / objection hierarchy (ranked) / awareness level
2. **10-Section Writing Roadmap**: Per section — goal, psychological principle, recommended word count, questions to ask within, what to avoid
3. **Emotional Trigger Map**: | Section | Primary Emotion | Trigger Technique | Example Line |
4. **Objection Templates** (5 buyer types): skeptic / price-sensitive / "tried before" / timing objector / "needs approval" — where in letter + exact language
5. **Proof Placement Strategy**: Where testimonials, data, case studies, authority logos go, how many of each type
6. **Flow & Pacing Summary**: Reading experience guide for the person writing the copy
