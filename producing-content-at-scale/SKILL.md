# Section A — Content Production Framework

## Inputs
Brand voice + tone, target audience + content consumption habits, content goal (leads/authority/engagement/SEO/retention), channels, team size + roles, publishing cadence goals, any existing content as reference.

## Deliverables

### Master Framework (Sheets)
| Content Pillar | Sub-topic | Format | Platform | Audience Stage | Hook Type | CTA | Repurpose From | Status |
Define 3–5 pillars, 5–10 sub-topics per pillar, format matrix per pillar.

### Editorial Calendar (3 months, Sheets)
| Date | Day | Platform | Title | Format | Pillar | Asset Status | Copy Status | Approved | Published |
Balance content types and pillars evenly. Include seasonal hooks and promotional windows.

### Content Approval Workflow
Brief submission format / review checklist (brand voice, accuracy, CTA) / feedback format / sign-off process / revision request protocol.

### Framework Application Prompt
A reusable prompt that takes any topic and outputs: title options, angle, key points, platform variations, CTA — apply to any new content piece going forward.

# Section B — Bulk Content Generation

## Inputs
Brand voice, audience, goal, platforms to produce for, topics or pillars.

## Generate 30 Production-Ready Pieces

**Blog/Long-form** (5): H1, H2 structure, intro hook, key points, CTA
**Email** (5): Subject, preview text, body, CTA
**LinkedIn** (5): Hook line, 3–5 short paragraph body, engagement CTA
**Instagram captions** (5): Hook, value, CTA, 3 hashtag set variations
**Short-form video scripts** (5): Hook (3s) + body (45s) + CTA (10s)
**Lead magnets** (5): Title, structure outline, key value points per section

Per piece: platform variation notes, character/word count compliance, visual asset brief (type, dimensions, key text, style reference).

# Section C — Visual & Design Assets

## Inputs
Brand colors, fonts, logo, design style references, asset type needed, dimensions/platform specs.

## Deliverables

### Canvas/Image Design Spec
For each asset:
- Dimensions and format
- Layout description (element placement, hierarchy)
- Typography: font choices, size, weight, color
- Color palette with hex codes
- Text content to include
- Mood/style reference
- Export format

### UI Design System
- Color tokens (primary, secondary, accent, neutral, semantic)
- Typography scale (H1–H6, body, caption, code)
- Spacing system (4px base grid)
- Component specs: buttons, cards, inputs, modals, nav
- Accessibility notes (contrast ratios, focus states)

### Visual Asset Library Plan
- Template structure for recurring formats (social post, email header, ad)
- Brand consistency rules (do/don't examples)
- File naming and folder organization convention

# Section D — Brainstorming & Ideation

## Inputs
Topic, niche, audience, goal, any constraints or existing ideas.

## Process
1. **Diverge**: Generate 30+ raw ideas without filtering — quantity over quality
2. **Cluster**: Group by theme, format, or audience stage
3. **Score**: Rank by originality × audience resonance × ease of production
4. **Develop top 10**: Expand each with angle, hook, format suggestion, platform fit
5. **Identify patterns**: Note which themes cluster — these are likely content pillars

## Output
- Raw idea list (30+)
- Clustered + scored top 10 with full brief
- Recommended content pillar implications
- 3 unexpected angles worth testing
